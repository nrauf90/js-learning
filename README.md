# Pakistan Income Tax Calculator

A web-based calculator for Pakistan FBR income tax on salaried individuals. Compare the **new tax regime** (FY 2025-26 & 2026-27) against the **previous 5 fiscal years** (FY 2020-21 through 2024-25).

## Features

- Calculate annual and monthly tax, take-home pay, and effective tax rate
- Switch between **New Tax** and **Old Tax** regimes
- Year-by-year comparison table across all 7 fiscal years
- Section 4AB surcharge support for high earners (above PKR 10M)
- Full tax slab reference table for the selected year

## Quick Start

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

| Command       | Description                    |
|---------------|--------------------------------|
| `npm start`   | Serve the app on port 3000     |
| `npm test`    | Run unit tests                 |
| `npm run lint`| Syntax-check JavaScript files  |

## Tax Years Covered

| Regime  | Fiscal Years                          |
|---------|---------------------------------------|
| New Tax | FY 2025-26, FY 2026-27               |
| Old Tax | FY 2020-21, 2021-22, 2022-23, 2023-24, 2024-25 |

## Disclaimer

Estimates are based on published FBR salaried individual tax slabs. Actual tax liability may differ based on deductions, exemptions, and individual circumstances.
