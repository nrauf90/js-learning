# M4 — Reports: weekly & monthly

**Phase:** 1  
**Goal:** Users view expense summaries and category breakdowns for weekly and monthly periods.

## Deliverables

- `GET /api/reports/weekly?start=YYYY-MM-DD`
- `GET /api/reports/monthly?year=YYYY&month=MM`
- `reports.html` + `js/reports.js` with Chart.js breakdown

## Tasks

See [M4 tasks](../tasks/M4-tasks.md).

## Exit criteria

- [ ] Weekly report shows total income, total expense, net, by-category totals
- [ ] Monthly report shows same aggregates for calendar month
- [ ] Chart renders category breakdown on the frontend
