# M32 — Dashboard customization

**Phase:** 7 (P3 polish) · **Depends on:** M31

**Goal:** Let users choose which widgets appear on their dashboard and in
what order, instead of the fixed layout.

## Scope

- Per-user dashboard preferences (which widgets: charts, goals, budgets,
  trial banner, etc., and order).
- Frontend: toggle/reorder UI on the dashboard.

## Tasks

See [M32 tasks](../tasks/M32-tasks.md).

## Exit criteria

- [ ] User can hide/show and reorder dashboard widgets
- [ ] Preference persists across sessions
- [ ] PHPUnit + E2E coverage
